🧋 Tiệm Trà Mơ Ước — Save Editor

Chỉnh save tsShop2 (JSON thuần). Chạy hoàn toàn trong trình duyệt — không gửi đi đâu.

1Lấy save ra khỏi game

Mở game trong trình duyệt → F12 → tab Console → dán lệnh này rồi copy chuỗi in ra:

copy(localStorage.getItem('tsShop2'))

copy(...) tự đưa save vào clipboard. Nếu không được, dùng localStorage.getItem('tsShop2') rồi copy tay.
